The 68.583-second first-encounter film pauses at each answer. Birth time uses a scroll wheel, gender has two choices, and each input offers a previous-answer control that preserves drafts. The compact fictional paper contract keeps one promise, both names and the explicit signature action, together with its scroll, paper, archive heading, star and seal. Input underlines remain visible while focused. Late video decoding automatically restores the correct waiting frame instead of leaving the meadow empty. Existing accounts enter their room directly, including after signing out and back in. Only newly registered accounts with an unfinished first encounter see Landing.

The handwritten welcome logo moves into the account form while turning black, with its visible ink aligned to the field labels. Login and registration share the account-first entry and matching pill-shaped input fields.

Chat centers the companion avatar and name. The upper-left diary and upper-right settings entries complement the card and sound controls. Settings links to the card, account and shared music/voice switch. White glass selection, quiet line icons and stronger previous-answer contrast refine onboarding. All chat bubbles use a single 90% white fill and retain glass blur, with the same soft edge as the brighter controls. All bottom sheets use 90% white with retained backdrop blur and white handles. Input placeholders use 10% black. Account and password fields use one 10% white background in both resting and focused states. Primary actions remain black, and glass buttons use one continuous capsule surface. Long chat bubbles fade softly at viewport edges while endpoint messages stay fully visible. Loading includes a small body hop and double blink; reduced motion remains static. The room includes 37 fixed demo lines recorded with the same Yunxia voice and prosody as the landing film. Arbitrary custom text uses the device voice fallback; there is no dynamic remote speech service.

Cotton-paper cards show an avatar, name, location/language, one-line introduction and up to seven distinct hand-drawn social-tag stickers. Their web and PNG layouts share the same paper and sticker drawing logic. Editing includes tag order, hiding and restoring confirmed historical tags from private journals. Tags lead to their source journal and original conversation. Sharing renders only the public card fields and supports link sharing and PNG export.

Journals provide a complete monthly calendar, month navigation, multiple entries per day, the original daily quote, confirmed tags and expandable source conversations.

Visit a tiny meadow world with gently uneven grass, simple sprout-roof homes, mist and distant islands: drag, scroll, or use arrow keys to turn the globe. Eight rooms show example portrait photos; the closest friend is largest. Tap an avatar to knock. The page title stays centered, and the world shows character loading while its assets become ready. Both participants bring their companions to the shared room.

Registration is a frontend prototype: it creates no remote account and stores no account credentials. Other sample state stays in this browser. The in-world contract is fictional. Existing demo account: `knoknok.demo` / `Knoknok2026`. The same-origin auth adapter remains available for backend integration.

The root static Pages demo is separate from the formal Web compatibility build. Existing `compat/web-naming`, `scripts`, `test`, package configuration and `docs/LANDING-HANDOFF.md` are preserved.

Local hosting must support HTTP byte ranges for film cue seeking. Private sources, original design explorations, tests, journal data and modeling files are excluded from this public runtime.

The production compatibility page follows the same account-level rule using the backend onboarding state; see [registration-only Landing](docs/first-landing.md) for the deployment dependency and verification scope.
