# Knoknok · Klin Demo

Interactive frontend prototype for team review.

Preview: https://xgen-labs.github.io/knoknok-demo/

Login, matching and conversations are simulated. Each browser keeps its own demo progress.

This repository contains the deployable web build and required browser assets. Original Blender projects and design history are not included.

## Local preview

Run `python3 -m http.server 8769` in this directory and open http://127.0.0.1:8769/.

## Hosting

GitHub Pages publishes the `main` branch from the repository root. A `.nojekyll` marker preserves the prebuilt static files.
