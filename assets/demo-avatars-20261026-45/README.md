# Demo contact portrait samples

These eight locally packaged photos illustrate fictional Knoknok Demo contacts. They are sample photos, not real Knoknok user accounts or endorsements. A contact's uploaded avatar takes precedence.

Source checked on 2026-10-26: [Random User portrait collection](https://randomuser.me/photos). Its [copyright notice](https://randomuser.me/copyright) says its photos come from UI Faces' authorized section. The linked [UI Faces usage guidance](https://web.archive.org/web/20160811185628/http://uifaces.com/faq) permits authorized portraits on live products and instructs using fictional names. These portraits are used only as fictional Demo avatars, not as testimonials.

Original JPEG bytes are retained. `sources.json` records each source URL, SHA-256, and size. The UI uses circular `object-fit: cover` crops centered on the face. No remote photo requests are made by the running Demo.
